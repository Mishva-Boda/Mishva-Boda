### `03` — Spotify Genre Segmentation & Recommendation

A machine-learning project exploring patterns across thousands of Spotify tracks.

The workflow covers data cleaning, exploratory analysis, feature analysis, **K-Means clustering**, **PCA**, visualization and content-based recommendation.

**Focus:**
`Python` · `Pandas` · `NumPy` · `Scikit-learn` · `K-Means` · `PCA` · `EDA`
